# img/ — site images, served from the site itself

Drop files here with these exact names (or any name — tell Claude and it'll wire them up).

| File | Used for | Spec |
|---|---|---|
| `bni-logo.png` (or `.svg`) | Header logo (currently hot-linked from an email CDN) | Transparent background. Displays 28px tall; supply ≥ 112px tall for sharp retina rendering. SVG preferred if you have it. |
| `favicon.png` | Browser tab icon | 32×32 or 48×48 PNG, square. |
| `apple-touch-icon.png` | Home-screen icon on iPhone/iPad | 180×180 PNG, square, non-transparent background. |
| `og-image.jpg` | Preview image when the link is shared (Facebook, iMessage, LinkedIn, Slack) | 1200×630 JPG/PNG, under ~300 KB. Optional. |

Only the logo is required to replace what's live today; the rest are additions.
